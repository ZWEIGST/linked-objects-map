# linked-object-map

Интерактивная карта связанных гео-объектов на **Vue 3 + TypeScript + Vite**. Карта использует тайлы OpenStreetMap без API-ключей; состояние фильтрации хранится в Pinia.

## Возможности

- маркеры из `src/data/mock.json`;
- одинаковый `title` → одинаковый цвет;
- группы из двух и более видимых объектов соединяются последовательной Polyline по `id`;
- отключение маркера автоматически перестраивает связи;
- клик по маркеру открывает popup с `title` и `description`;
- клик по карточке центрирует карту на объекте и открывает popup;
- «Очистить» скрывает все объекты и очищает список;
- «Поиск» восстанавливает объекты, чекбоксы и исходный viewport;
- адаптивная верстка для небольших экранов;
- деплой на Vercel через GitHub.

## Локальный запуск

Требуется Node.js `22.18+` или `24.12+`.

```bash
npm install
npm run dev
```

Проверка production-сборки локально:

```bash
npm run type-check
npm run build
```

## Деплой на Vercel

1. Создайте репозиторий на GitHub с именем `linked-object-map` и загрузите содержимое проекта.
2. В Vercel выберите **Add New → Project** и импортируйте этот GitHub-репозиторий.
3. Vercel автоматически определит Vite-проект. Используйте стандартные настройки:
   - Build Command: `npm run build`
   - Output Directory: `dist`
   - Install Command: `npm install`
4. Нажмите **Deploy**.

Для проекта не требуется GitHub Actions: Vercel будет автоматически пересобирать приложение после push в подключённую ветку.

## Источник карты
