Интерактивная карта связанных гео-объектов на **Vue 3 + TypeScript + Vite**. Карта использует тайлы OpenStreetMap без API-ключей; состояние фильтрации хранится в Pinia.

## Описание

- маркеры из src/data/mock.json;
- одинаковый title === одинаковый цвет;
- группы из двух и более видимых объектов соединяются последовательной Polyline по id;
- отключение маркера автоматически перестраивает связи;
- клик по маркеру открывает popup с title и description;
- клик по карточке центрирует карту на объекте и открывает popup;
- «Очистить» скрывает все объекты и очищает список;
- «Поиск» восстанавливает объекты, чекбоксы и исходный viewport;
- адаптивная верстка для небольших экранов.

## Локальный запуск

Требуется Node.js версии 22.18+ или 24.12+.

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run type-check
npm run build
```
